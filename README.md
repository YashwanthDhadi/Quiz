# 🎓 Quiz App

An interactive web-based quiz application built using HTML, CSS, and JavaScript. Users can enter their name, choose from multiple quiz categories, answer questions, and receive an instant score report at the end.

## 🚀 Features

* 👤 User name entry before starting
* 📚 Multiple quiz categories
* 🎬 Movies & Cinema
* 🏪 Guess the Brand
* ⚽ Sports Trivia
* 🧠 Quick Aptitude
* 🛠️ Tech & Engineering
* 🇮🇳 History & Culture
* 🤔 Fun Facts & Curiosities
* 🌿 Nature & Life
* ✅ Instant answer validation
* 📊 Score and percentage calculation
* 🎉 Interactive result screen
* 📱 Responsive design for desktop and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

1. Clone the repository


2. Open the project folder

3. Launch:

```text
index.html
```

or run using VS Code Live Server.

## 🎮 How It Works

1. Enter your name
2. Select a quiz category
3. Answer all questions
4. View your final score and percentage
5. Try another category and improve your score
